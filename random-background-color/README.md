# Random Background Color Changer

A beginner-friendly JavaScript project that changes the background color randomly when clicking a button.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Random HEX color generation
- Smooth background transition
- Displays current color code

## Project Structure
random-background-color/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run
1. Download the project
2. Open index.html in your browser
