# TicTacToe — X vs O 🎮

A sleek, cyberpunk-themed Tic Tac Toe game built with pure **HTML**, **CSS**, and **JavaScript** — no frameworks, no dependencies.

---

## 📁 Project Structure

```
tictactoe/
├── index.html   → Game markup & structure
├── style.css    → Cyberpunk dark theme & animations
├── script.js    → Game logic & interactivity
└── README.md    → You are here
```

---

## ✨ Features

- 🎨 **Cyberpunk dark UI** — animated grid background, neon glow effects, floating orbs
- 🔤 **Custom Orbitron font** — futuristic display typography
- 🟦 **Player X** — neon cyan (`#00f0ff`) with glow
- 🟧 **Player O** — hot pink (`#ff4fa3`) with glow
- 📊 **Live scoreboard** — tracks X wins, O wins, and draws across rounds
- 🏆 **Win modal** — animated popup showing winner with play again option
- ✅ **Win highlight** — winning cells pulse and glow
- 📱 **Responsive design** — works on mobile and desktop
- ⚡ **Zero dependencies** — pure vanilla HTML/CSS/JS

## 🎮 How to Play

| Action | Description |
|--------|-------------|
| Click a cell | Place your mark (X or O) |
| **↺ New Round** | Reset the board, keep scores |
| **✕ Reset Scores** | Clear all scores and start fresh |
| Win modal → **Play Again** | Start a new round |

- Players alternate turns: **X goes first**
- First to get **3 in a row** (horizontal, vertical, or diagonal) wins
- If all 9 cells are filled with no winner → **Draw**
