# 🎮 Console Clash

A simple and modern PS5 vs Xbox interactive landing page built with HTML and CSS.

## ✨ Features

* Split Screen Layout
* PS5 vs Xbox Showcase
* Smooth Hover Expansion Animation
* Responsive Design
* Flexbox Layout

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📚 Concepts Practiced

* Flexbox
* Hover Effects
* CSS Transitions
* Responsive Design

## 🚀 How It Works

When the user hovers over a console panel, it expands smoothly while the other panel shrinks, creating an engaging interactive effect.
